# Grocery Manager App
Make your grocery management easier and more organized with a simple and efficient system that helps you plan, track, and manage everything without the usual hassle.

## 📦 Installation

1. Install Grocery 1.0.zip
2. Extract the ZIP file  
3. Open the folder named **"Grocery 1.0"**  
4. Go into the **android** directory  
5. Install **app-release.apk**  
6. All set — Enjoy!


## Extra Info

For those interested in how this app was built:

I initially developed it using **HTML** because I was working with a low-spec system that couldn’t comfortably run Android Studio. I started with what was lightweight and accessible, then gradually improved the project by adding features and refinements.

I used tools like **Claude** and **ChatGPT** to enhance and optimize the code and overall structure.

Finally, I converted the web app into an Android APK using:
https://www.webintoapp.com/

This approach can also be useful for beginners who want to build Android apps without heavy development setups like Android Studio.
